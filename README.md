# DT_Tools

《[Deadly Trick](https://store.steampowered.com/app/3088400/Deadly_Trick/)》 功能增强插件

---

《[Deadly Trick](https://store.steampowered.com/app/3088400/Deadly_Trick/)》是一款基于 P2P 局域网联机的派对社交推理游戏。  
本 Mod 基于 BepInEx 框架开发。

> [!WARNING]
> 从版本 [**0.1.10**](https://store.steampowered.com/news/app/3088400/view/696523089338434233) 开始, 游戏将检测 **梅德琳** 与 **付费表情包**.  
> **本项仅供学习和技术交流使用，严禁用于任何公开匹配或商业用途。**  
> 因使用本插件带来的任何后果，**完全由使用者自行承担**。

## 功能列表

| 功能 | 说明 | 默认状态 |
| :--- | :--- | :--- |
| 游戏测试模式 | 启用游戏测试模式 | ❌ 禁用 |
| 表情包全解锁 | 解锁所有表情包 | ❌ 禁用 |
| 表情发送无 CD | 可连续使用表情动作 | ✅ 启用 |
| 黑方刀人距离 | 自定义黑方攻击范围 | ❌ 禁用 |
| 黑幕递刀距离 | 自定义黑幕递刀范围 | ❌ 禁用 |
| 全状态移速调整 | 分别调整各动作移速倍率 | ❌ 禁用 |
| 大厅移速调整 | 调整大厅内移速倍率 | ❌ 禁用 |
| 房间人数上限 | 修改开房最多人数 | ❌ 禁用 |
| 房间人数下限 | 修改开房最少人数 | ❌ 禁用 |
| 黑幕伪证支持 | 允许黑幕使用伪证功能 | ❌ 禁用 |
| 去除地图迷雾 | 关闭房间阴影遮罩 | ❌ 禁用 |
| 小地图透视 | 小地图显示全部玩家位置 | ❌ 禁用 |
| 幽灵视角 | 强制以幽灵视角进入游戏 | ❌ 禁用 |

## 安装方法

1. 确保游戏已安装 [BepInEx](https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.5) 运行环境。
2. 将 `DT_Tools.dll` 放入 `Deadly Trick\BepInEx\plugins\` 目录。
3. 启动游戏，配置文件将自动生成于 `Deadly Trick\BepInEx\config\DT_Tools.cfg`。
4. 按需编辑配置文件，启用或禁用相应功能。

## 使用注意
请关闭 Steam 云同步，避免破坏云存档。（除非你觉得无所谓）

下载 Steam 云存档到本地的 `%USERPROFILE%\AppData\LocalLow\FinalBlow\DeadlyTrick` 目录中。
